## Detailed Findings

### P3 — Responsive: item pagination di mobile

- **Location:** semua tabel halaman (pending & riwayat) — `.ant-pagination-item` antd default ±32px.
- **Impact:** tap target di bawah floor 44px project (AA WCAG 2.5.8 tetap lolos karena ≥24px — bukan pelanggaran WCAG, tapi di bawah floor project).
- **Recommendation:** tambah `.ant-pagination-item{min-height:44px}` di block mobile (≤768px) `globals.css`.
- **Suggested command:** `/impeccable polish`

### P3 — Responsive: tabel riwayat masih scroll horizontal ±700px di mobile

- **Location:** tab Riwayat mobile (`scroll.x: 700`, 5 kolom).
- **Impact:** masih ada scroll horizontal, tapi semua kolom ramping, catatan admin tampil penuh tanpa hover; data referensi read-only — pola diterima, bukan cacat.
- **Status:** documented trade-off (fix-005). Tidak di-escalate.

### P3 — Theming: fallback `#f0f0f0`

- **Location:** `RequestBarang.tsx` L469 (`borderBottom: '1px solid var(--ant-color-border-secondary, #f0f0f0)'`).
- **Status:** fallback token AntD sah, bukan literal desain — tidak di-escalate.
