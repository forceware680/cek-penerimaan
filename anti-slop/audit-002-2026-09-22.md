## Detailed Findings

### P2 — Responsive: tabel Riwayat (admin "Semua Riwayat" & non-admin "Riwayat Saya")

- **Location:** `RequestBarang.tsx`, tab `history` (`scroll={{ x: 900 }}`); kolom "Catatan Admin" (lebar 220, ellipsis 200).
- **Impact:** Di ponsel (≈375px) isi tabel harus di-scroll horizontal ±500px; isi "Catatan Admin" terpotong dan tooltip-nya hover-centric (awkward di touch).
- **Catatan konteks:** data read-only referensi — scroll horizontal masih pola yang diterima, bukan P0/P1.
- **Recommendation:** versi mobile: sembunyikan/rapatkan kolom "Catatan Admin" di ≤768px (atau kartu ringkas), biarkan tabel desktop utuh.
- **Suggested command:** `/impeccable adapt`

### P2 — A11y: modal Tolak / reject massal

- **Location:** `RequestBarang.tsx`, `handleReject` & `handleBulkReject` (`antModal.confirm` + `TextArea`).
- **Impact:** Screen reader tidak punya label programatik untuk field alasan (hanya `<Text>` visual di atasnya).
- **Recommendation:** beri `id` + `aria-labelledby` pada TextArea dari teks instruksi, atau pindahkan alur ke Form Item berlabel.
- **Suggested command:** `/impeccable harden`

### P3 — A11y: list kartu pending mobile

- **Location:** `RequestBarang.tsx`, `pendingMobileList`.
- **Impact:** Status loading tidak diumumkan (Spin tampil visual saja).
- **Recommendation:** `aria-busy={loading}` di container list.
- **Suggested command:** `/impeccable harden`

### P3 — Theming: hex literal inline & badge color (pre-existing, di luar scope fix-004)

- **Location:** `RequestBarang.tsx`: `#FFF3C4` (bulk bar), `#F5F0DF` (kartu info modal), `#4a4a44` (beberapa teks), badge `#f5222d`.
- **Impact:** Inkonsistensi token kecil; nilai identik sudah ada di `:root` (`--accent-tint`, `--paper-dark`/`--text-soft`, `--danger`).
- **Recommendation:** tokenize saat pass berikutnya (aturan project: hex literal tidak boleh di rule CSS — inline masih pola incumbent).
- **Suggested command:** `/impeccable polish`

### P3 — Implementation Integrity: detector warning stripe login

- **Location:** `globals.css:69` `.login-card::before`.
- **Status:** verified false positive — motif identitas incumbent (lihat fix-002/003). Tidak di-touch.
