# Anti Slop Fix 004 — Manajemen Request Kode Barang: Responsif Mobile

- **Date:** 2026-09-22
- **Direction:** NEOBRUTALISM (sistem incumbent; adapt desktop → mobile, bukan scaling)
- **Scope:** UI saja — tab admin "Menunggu Persetujuan" di mobile + bug CSS header. **Backend tidak disentuh.** Desktop, form pengajuan, riwayat, dan modal approve/reject tidak berubah perilakunya.

## Diagnosis

1. **Tabel pending admin** `scroll.x: 900` + kolom aksi `fixed: right`: di ponsel (≈375px) detail barang (User/OPD, [ObjekRSSub], Keterangan, satuan/tipe) harus di-scroll horizontal untuk dibaca, padahal tombol Approve/Tolak selalu tampil di kanan — admin tidak bisa menilai request yang sedang di-approve. Ini inti keluhan "belum responsif".
2. **Bug CSS header:** `.rb-header .ant-typography { font-size: 20px }` (block ≤768px) kena semua elemen Typography karena Title dan sub-Text sama-sama kelas `ant-typography` → subjudul header membesar 20px di mobile.
3. **Label tab panjang** ("Menunggu Persetujui" + "Semua Riwayat") overflow bar tab di layar 375px.
4. **Tombol aksi tabel** `shape="circle"` lebar 32px (global hanya memaksakan `min-height: 44px`) → tap target bawah floor 44px.

## What changed

| File | Change |
|---|---|
| `src/components/RequestBarang.tsx` | Hook `useIsMobile()` (matchMedia ≤768px, sinkron dengan mobile block globals.css). Tab "Menunggu" admin di mobile dirender sebagai **kartu bertumpuk** (`rb-pending-list`): checkbox selection per kartu, tag MENUNGGU, user/OPD, `[ObjekRSSub] KetObjekRSSub`, keterangan, satuan/tipe, Req ID, tanggal submit, dan dua tombol full-width **Setujui** / **Tolak** (min-height 44 via global). Bulk bar dipindah ke variabel `bulkBar` (pakai di desktop & mobile). Label tab dipendekkan di mobile: "Menunggu" / "Riwayat". Helper `formatDateTime` + `openApprove` di-extract (di-reuse tabel & kartu). Empty state = kartu neobrutal + `Empty`; loading = `Spin` saat daftar kosong. |
| `src/app/globals.css` | Header mobile: rule diubah `.rb-header .ant-typography` → `.rb-header h3.ant-typography` (judul saja; subjudul kembali 13px). Block mobile (≤768px) ditambah `.rb-pending-list/-card/-top/-user/-objek/-meta/-date/-actions/-empty` — token `var(--*)` (`--surface`, `--ink`, `--text-soft`), kartu 2px ink + radius 12 + hard shadow `6px 6px 0` (sistem neobrutal), checkbox wrapper min-height 44px, aksi `flex: 1` (dua tombol setara), `overflow-wrap: anywhere` di teks meta (sesuai aturan tabel fixed-layout). |

## Alasan

- **Kartu bukan scaling tabel:** pola tabel→kartu adalah responsi standar untuk data actionable di mobile; detail + keputusan (approve/reject) jadi satu unit per request, jangkauan jempol, tanpa scroll horizontal.
- **Tabel tetap di desktop & riwayat:** riwayat read-only — scroll horizontal tetap pola yang benar untuk referensi data; tidak diubah.
- **Satu breakpoint (768px):** sama dengan mobile block CSS; tidak menambah breakpoint baru.
- **Bulk approve/reject tetap jalan** di mobile via checkbox per kartu + bulk bar yang sudah wrap.

## Tap target / a11y

- Checkbox kartu: wrapper 44px (`min-height: 44px`).
- Tombol Setujui/Tolak: `block` + `flex: 1` + global `.ant-btn min-height: 44px` → ≈44px tinggi, lebar ≥150px di 375px.
