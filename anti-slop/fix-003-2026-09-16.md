## One-line reasons (R-31)

- **Dark mode removed:** one light system eliminates two competing override stacks; the ink sider keeps the dashboard loud without a second theme (owner: conflicts).
- **AntD kept as the engine, CSS as the skin:** Table/Modal/DatePicker/Segmented/Pagination stay AntD (backend and data untouched); every visible surface is overridden to the system language, with `!important` because AntD injects styles after this file.
- **Sidebar = solid ink `#141414`:** the dark block of the layout; menu items are white-text chips, selected = yellow chip with ink text (700 weight) — the accent does the navigation work.
- **Buttons:** white chip + 2px ink border + 3px 3px 0 hard shadow; primary = yellow (`#FFD23F`, ink text 12.8:1); danger = white with red frame + red hard shadow; press-in 80ms on hover/active (the only motion).
- **Focus state = yellow hard shadow** (instead of a blue glow): a visible state change that fits the system; error state = red hard shadow (same language as the login).
- **Tabs/Segmented/Pagination/Checkbox/Tag:** all reframed in the same border+shadow language; status tags keep meaning via colored ink-style borders (blue 4.9:1, green 5.0:1, red 5.2:1, purple 5.7:1 on white).
- **Typography:** body Space Grotesk; page titles (H1–H3) Archivo Black — the loud display voice, matching the login.
- **Popover arrow hidden:** a 2px frame plus an arrow patch would break the frame; the framed panel reads clearly without it.
- **Toast/alert icons keep state colors:** driven by the token set (ink info, green success, red error) so meaning survives the restyle.
