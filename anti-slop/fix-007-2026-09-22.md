# Anti Slop Fix 007 — Pagination Mobile: Tap Target 44px

- **Date:** 2026-09-22
- **Sumber:** item P3 terakhir dari `/impeccable audit` (audit-003) — `/impeccable polish`
- **Scope:** satu rule di block mobile `globals.css`. Tidak menyentuh komponen.

## Change

`src/app/globals.css` — block `@media (max-width: 768px)`, seksi touch targets:

```css
/* antd v6 sets a fixed 32px height on pagination items via CSS-in-JS,
   so the floor needs !important to win (same rule as other targets). */
.ant-pagination-item {
  min-height: 44px !important;
}
```

`!important` wajib karena CSS-in-JS AntD v6 di-inject setelah globals.css dan menetapkan tinggi 32px eksplisit pada `.ant-pagination-item` (aturan strategi CSS project). Tombol prev/next pagination sudah tercakup rule `.ant-btn{min-height:44px}` yang ada.
