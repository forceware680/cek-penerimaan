# Anti Slop Fix 005 — Request Kode Barang: Adapt Tabel Riwayat Mobile + Harden A11y

- **Date:** 2026-09-22
- **Sumber:** hasil `/impeccable audit` (audit-002) — menjalankan rekomendasi **adapt** (P2) dan **harden** (P2/P3)
- **Scope:** UI saja. Desktop, pending, form, modal approve tidak berubah perilakunya.

## What changed

| File | Change |
|---|---|
| `src/components/RequestBarang.tsx` | **(adapt)** Tabel Riwayat di ≤768px (admin & non-admin) memakai `mobileHistoryColumns`: kolom Barang+Satuan+Tipe digabung jadi satu (meta line `.rb-hist-meta` + Req ID opsional), kolom "Catatan Admin" tampil **teks penuh tanpa ellipsis/tooltip** (lebar 180, wrap), `scroll.x` 900 → 700. Render sel Tgl (`tanggalShort`) dan User/OPD (`userOpdCell`) di-extract agar dipakai tabel desktop & mobile. **(harden)** Modal reject & reject massal: instruksi diberi `id` (`rb-reject-instr` / `rb-bulk-reject-instr`) dan `TextArea` diberi `aria-labelledby` → label programatik untuk screen reader. Container list pending mobile diberi `aria-busy={loading}`. |
| `src/app/globals.css` | Block mobile (≤768px) tambah `.rb-hist-meta` (11px, `var(--text-soft)`, `overflow-wrap: anywhere`) — meta line kolom Barang gabungan. |

## Alasan

- **Gabung kolom, bukan kartu:** riwayat = data referensi read-only; tabel tetap pola yang benar, tapi di ponsel hanya 5 kolom ramping (Tgl / User / Barang-gabungan / Status / Catatan penuh) sehingga scroll horizontal berkurang ±200px dan setiap baris bisa dinilai tanpa hover.
- **Catatan penuh, bukan tooltip:** alasan penolakan adalah informasi inti bagi pengaju — hover-tooltip di touch tidak andal; teks wrap (global `overflow-wrap: anywhere` di sel tabel) menjadikannya terbaca langsung.
- **aria-labelledby, bukan label[htmlFor]:** antd TextArea menerima ARIA props langsung di elemen `textarea`; mengasosiasikan teks instruksi yang sudah ada menjaga copy tidak berubah.
- **aria-busy:** status loading list mobile kini diumumkan, bukan hanya visual Spin.
