# Anti Slop Fix 006 — Request Kode Barang: Polish (Tokenisasi Hex Inline)

- **Date:** 2026-09-22
- **Sumber:** item P3 terakhir dari `/impeccable audit` (audit-002) — dijalankan `/impeccable polish`
- **Scope:** `src/components/RequestBarang.tsx` saja — hex literal inline → token `:root`. Tidak ada perubahan perilaku/nilai warna (kecuali dua yang didokumentasikan di bawah).

## Mapping yang dipakai

| Inline lama | Token | Catatan |
|---|---|---|
| `#4a4a44` (2× sel User/OPD) | `var(--text-soft)` | nilai identik |
| `#141414` (8×: header title, detail barang, bulk bar border/shadow/text, icon form, icon modal) | `var(--ink)` | nilai identik |
| `#FFF3C4` (bulk bar) | `var(--accent-tint)` | nilai identik |
| `#FFD23F` (icon chip form) | `var(--accent)` | nilai identik |
| `#f5222d` (badge tab pending) | `var(--danger)` | **pergeseran kecil** `#f5222d` → `#D61F1F`: badge kini konsisten dengan satu aksen danger sistem |
| `#F5F0DF` (kartu info modal approve) | `var(--paper)` | **pergeseran kecil** `#F5F0DF` → `#f6f1e4` (ΔE nyaris tak terlihat; memakai token paper yang memang motif tint sistem) |

Tersengol sengaja: `var(--ant-color-border-secondary, #f0f0f0)` di header — fallback token AntD, bukan literal desain.
